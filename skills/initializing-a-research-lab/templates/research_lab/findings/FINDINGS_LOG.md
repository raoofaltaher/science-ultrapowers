# Findings log

This file is append-only. The rules are in `science-ultrapowers:recording-findings`: never edit a verified row; supersede it with a new FND-id instead. Every number in any lab document must be quoted from here or from `KEY_RESULTS.md`. Status is `tentative`, `verified`, `superseded by FND-xxxx` or `refuted by FND-xxxx`. Rows written before this layout keep their old ids (F-xxxx), which stay valid. Basis is `confirmatory` (a registered protocol whose registration check is clear and a run that matched it) or `exploratory` (everything else); a row written before the Basis column existed reads `exploratory`.
