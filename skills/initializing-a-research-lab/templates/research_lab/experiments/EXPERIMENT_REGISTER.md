# Experiment register

The schema is in `science-ultrapowers:recording-findings`. Register a run before it starts, with the checksum of every raw input in Input checksums; a test split, where the project has one, is used only in a preregistered final evaluation. Status is `planned`, `feasibility`, `registered`, `running`, `completed`, `failed` or `aborted` (with the reason).
